# MOC-diverging-nozzle
This python script takes entry Mach, exit Mach, ratio of specific heats and throat height as input and generates the nozzle profile.
I have also included bash script "run_graphs" which generates the nozzle profile with transparent background.

This nozzle profile is for entry Mach = 2, exit Mach = 4, throat height = 1, ratio of specific heats = 1.4
